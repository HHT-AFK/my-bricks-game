# my-bricks-game
默认首页变为「旅程」：塔有十层，每层对应词书 150 词（1–150、151–300……），每一层都是一段原创故事——从第一章「塔影林道」追进黑森林，途经「腐朽回廊」「断桥峡谷」「星象大厅」，直到第十层「遗忘之巅」面对魔王救出公主。 学习挂在主线上：每层「学习本章词汇」只出这一层的 150 词（卡片式、艾宾浩斯复习照旧），章节新词每次 25 个、不占每日上限，学完可继续。 战斗锁进章节：本章学满 10 词后可「挑战守卫」——战斗题目池锁定为该层词汇，胜利即「封印此层」，自动解锁上一层。封印进度显示在塔头图进度条上。 原有功能全保留：仪表盘、词书浏览、生词本、自由闯关（原五关塔）、学习记录、设置一个不少，仪表盘上还加了旅程入口。
